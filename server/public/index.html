QueueSmart API Documentation

The backend is running !

Read below for API endpoints and usages.

Implemented!!

These routes are able to be used. *Note: may need more development.

System

GET/api/health

Checks whether the QueueSmart server is running. Returns "ok" if yes.

Authentication

POST/api/auth/login

Authenticates a administrator or user.

Services

GET/api/services

Returns a list of services for the current administrator or organization. Use params ...... for filtering response.

POST/api/services

Creates a new service for an administrator or organization.

PATCH/api/services/:serviceId

Updates the details (name, description, duration, status etc) of a service.

GET/api/services/:serviceId

Returns the detail of one service.

DELETE/api/services/:serviceId

Deletes a service from the administrator/organization.

Queues

GET/api/queues/:serviceId

Returns the current queue for a selected service.

POST/api/queues/:serviceId/join

Admits user to selected service queue.

POST/api/queues/:serviceId/leave

Ends user's current queue session.

POST/api/queues/:serviceId/serve-next

Allows administrator to serve the next user in the queue.

PATCH/api/queues/:serviceId/reorder

Allows the administrator to modify the order of upcoming users in service's queue.

DELETE/api/queues/:serviceId/users/:userId

Removes a user from a the queue of the selected service.

Authentication

POST/api/auth/register

Registers a new administrator or user.

GET/api/auth/me

Returns the currently signed in admin/organiation or user. Use for session state tracking.

Wait-Time Estimation

GET/api/queues/:serviceId/wait-time

Returns the estimated wait-time for a service.

GET/api/users/:userId/queues/current

Returns the user's current position in the queue, their estimated wait time, and their status (joined/unjoined?). Status can be used for triggering reminders to join queues or prepare for service.

Notifications

GET/api/users/:userId/notifications

Returns user/admin notifications (queue updates, reminders, new appmt etc).

POST//api/users/:userId/notifications

Creates a new notification.

PATCH/api/notifications/:notificationId/read

Marks a notification as read.

History

GET/api/history

Returns a user's or administrator's queue session history.

POST/api/history

Add's an event and status (completed, left, served) to a user's or administrator's queue session history.

Admin Statistics/Usages

GET/api/admin/stats

Returns all the statistics of all services and administrator/organization usage. Use params ...... for filtering response.

GET/api/admin/services/summary

Returns a summary of details of a service provided.
